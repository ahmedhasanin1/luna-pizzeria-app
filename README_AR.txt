Luna Pizzeria PWA for GitHub Pages
==================================
1) فك ضغط الملف.
2) في GitHub أنشئ مستودعًا عامًا جديدًا باسم luna-pizzeria-app.
3) ارفع كل محتويات هذا المجلد إلى جذر المستودع (index.html وmanifest.json وservice-worker.js ومجلد icons).
4) Settings > Pages > Deploy from a branch > main > /(root) > Save.
5) انتظر رابط GitHub Pages ثم افتحه في Chrome على Android.
6) من قائمة Chrome اختر Install app أو Add to Home screen.

ملاحظات:
- هذا غلاف تثبيت ويب، وليس APK.
- يعتمد على رابط Apps Script الحالي المضمّن في index.html.
- يجب اختبار ظهور النظام وتسجيل الدخول والحجز والتقارير والطباعة بعد النشر. إذا منع Google Apps Script العرض داخل iframe أو فتح تسجيل الدخول، سنعدل طريقة العرض.
- لا تضع أي كلمات مرور أو بيانات سرية داخل ملفات GitHub.
